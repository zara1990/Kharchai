# KharchAI — AI Financial Copilot for Pakistan

## Project Overview
KharchAI is an AI-powered Android financial copilot app built for Pakistan. It will be developed as a milestone-by-milestone vertical-slice build.

## Architecture (planned)
- **Mobile**: Expo React Native (Android-first)
- **Backend**: Python FastAPI

## Workflow Rules
- Inspect the repository before making any changes.
- Build one small vertical slice at a time — wait for a specific milestone prompt before implementing features.
- Do not introduce unnecessary technologies or dependencies.
- Do not build the entire application in one step.
- Features NOT in scope until explicitly requested:
  - OpenAI / LLM integration
  - Authentication
  - Dashboard UI
  - Receipt AI / OCR

## Repository
Connected to GitHub. Commit and push after each milestone.

## User Preferences
- Controlled, milestone-by-milestone vibe-coding workflow.
- Agent must inspect the repo before making changes.
- No speculative features — only build what is explicitly asked for.
