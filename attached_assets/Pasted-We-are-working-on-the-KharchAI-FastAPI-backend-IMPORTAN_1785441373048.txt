- PASS
- WARNING
- FAIL

Return FAIL.

If slightly blurry:
Return WARNING.

B. Brightness

Calculate average grayscale brightness.

Detect:

Too Dark

Too Bright

C. Resolution

Reject images smaller than approximately:

1000 px width
OR
1000 px height

D. Long Receipt Detection

Estimate aspect ratio.

If receipt height is much larger than width
(example >3.5:1)

Return:

is_long_receipt = true

Do NOT reject.

Return a warning message:

"This receipt looks very long. Capture it in 2–3 overlapping photos for better accuracy."
